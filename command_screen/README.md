# شاشة القائد — نظام إدارة العمليات والمشروعات (الجزء الثاني)

برنامج مستقل وخفيف يعرض على القيادة كل الفاكسات التي ضغط فيها المشغل «حفظ وتمرير إلى القيادة» في محطة المشروعات.
سيرفر وقاعدة بيانات خاصان به، ويعمل على البورت **8766**. الشاشة تتحدث فورًا بدون Refresh، ولو المحطة توقفت تستمر بعرض آخر موقف مع مؤشر اتصال أحمر.

## التشغيل على Windows
1. لازم Python 3.10+ متسطّب (نفس متطلبات الجزء الأول).
2. دبل كليك على **START_COMMAND.bat**.
   - أول مرة بيجهّز بيئة التشغيل من فولدر `wheels` (بدون إنترنت)، أو بيستخدم بيئة محطة المشروعات لو موجودة جنبها.
   - المتصفح يفتح على http://127.0.0.1:8766
3. **START_ALL.bat** (في الفولدر الرئيسي) يشغّل البرنامجين معًا ويفتح تبويبين: المحطة والقائد.

## عند النقل إلى جهاز ثاني
- انسخ فولدر `command_screen` كاملًا للجهاز الثاني وشغّل `START_COMMAND.bat`.
- افتح ⚙️ الإعدادات في الشاشة وغيّر «عنوان محطة المشروعات» إلى عنوان الجهاز الأول (مثل `http://192.168.1.10:8765`).
- لا يحتاج أي تعديل في الكود — المحطة لازم تكون شغالة وعلى نفس الشبكة المحلية.

## المزايا
- **الشريط العلوي**: أعطال نشطة، مشروعات جارية، تنسيق متأخر، بلاغات حرجة، مفارز في مأمورية، وحالة الاتصال بوقت آخر تحديث.
- **الخريطة العملياتية**: خريطة محلية بدون إنترنت، المسارات المتضررة والعمليات الجارية مميزة بألوانها، والتفاصيل الكاملة للفاكس (ملخص، تقدير فني، احتياجات، تتبع، الفاكس الأصلي).
- **سجل العمليات**: كل ما اتمرر مع فلاتر (النوع/الحالة/الأولوية/بحث).
- **البيانات المرجعية**: المسارات والوصلات والأطقم — للعرض فقط.
- **التنبيه العاجل**: بلاغ حرج أو عطل متكرر → Pop-up أحمر بصوت تنبيه، فيه تاريخ آخر إصلاح وسببه والإجراءات، وزرار «تم الاطلاع».
- **أوامر القائد** (تُنفذ على سيرفر المحطة وتُسجل في سجل التدقيق باسم جهاز القائد):
  - تصديق الاحتياجات لكل بند: متاح / يحتاج تصديق / عجز
  - تغيير درجة الأهمية
  - توجيه مكتوب يظهر فورًا Pop-up لدى مشغل المحطة ويُسجل في التتبع
  - تأكيد الاطلاع على البلاغ (ويُوسم الفاكس «مقروء»)

## البيانات
- اسم الجهاز الافتراضي «جهاز القيادة» — يتغير بمتغير البيئة `CS_DEVICE_NAME`.
- قاعدة البيانات: `data/command_screen.db` — نسخ محلية من الفاكسات الممررة + الملفات الأصلية في `data/uploads/`.
- المزامنة: سحب كل ثانيتين من `GET /api/command/feed` في المحطة، مع تأكيد الاستلام `/api/command/ack`.
- لاحتفاظ ببياناتك عند تحديث البرنامج انسخ فولدر `data` من النسخة القديمة.

## للمطورين
- `pip install -r requirements.txt pytest httpx` وبعدها `python -m pytest tests`
- توثيق الـ API: http://127.0.0.1:8766/api/docs
