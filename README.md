# نظام إدارة العمليات والمشروعات

> **محطة قسم المشروعات + شاشة القائد** — نظام محلي متكامل لإدارة بلاغات الأعطال والمشروعات، يعمل على جهاز واحد أو جهازين، **بدون إنترنت**.

نظام عربي (RTL) مكوّن من برنامجين مستقلين يتواصلان عبر شبكة محلية:

| البرنامج | الدور | المنفذ | قاعدة البيانات |
|---|---|---|---|
| **محطة المشروعات** | واجهة المشغّل: استقبال الفاكسات، التحديد على الخريطة، التقدير الفني، الاحتياجات، المزامنة للقيادة | `8765` | SQLite خاصة |
| **شاشة القائد** | واجهة القيادة: خريطة عملياتية، سجل العمليات، أوامر القيادة، التنبيهات العاجلة | `8766` | SQLite خاصة |

---

## المميزات الرئيسية

### محطة المشروعات (Projects Station)
- تسجيل بلاغات/فاكسات جديدة مع إرفاق **الملف الأصلي** (PDF / صور) — مع استخراج النص تلقائيًا من ملفات PDF.
- تحديد موقع العطل على **خريطة تفاعلية** (Leaflet) مع مسارات وأطقم ومفاصل مرجعية.
- **محرك تقدير فني**: حساب أطوال الكابلات، اللحامات، ساعات العمل — مع إمكانية التعديل اليدوي.
- قوائم احتياجات لكل بلاغ + تتبع زمني كامل + سجل تدقيق (Audit Log).
- زر **«حفظ وتمرير إلى القيادة»** لإرسال البلاغ للقائد فقط عند الحاجة.
- صندوق وارد لأوامر القائد مع **تنبيه صوتي فوري** وPop-up.

### شاشة القائد (Command Screen)
- **مزامنة تلقائية كل ثانيتين** عبر polling + تأكيد استلام — مع SSE لتحديث فوري داخل المتصفح.
- **استمرارية**: لو انقطعت المحطة، تظل تعرض آخر موقف معروف مع مؤشر أحمر «غير متصل».
- مؤشرات علوية: أعطال نشطة، مشروعات جارية، تنسيق متأخر، بلاغات حرجة، مفارز في مأمورية.
- خريطة عملياتية تبرز المسارات والأعطال + سجل عمليات قابل للفلترة + بيانات مرجعية (مسارات/وصلات/أطقم).
- **تنبيه عاجل أحمر بصوت** عند البلاغات الحرجة أو الأعطال المتكررة (مع تاريخ آخر إصلاح والسبب والإجراءات).
- أوامر القيادة تُنفَّذ فعليًا على المحطة: تصديق الاحتياجات، تغيير الأولوية، توجيه مكتوب، تأكيد الاطلاع — كلها موثقة باسم الجهاز.
- **وضع فاتح/داكن** + تحديث تلقائي اختياري (معطل / 5 / 10 / 30 دقيقة).

### غير وظيفية
- **صفر إنترنت**: كل شيء محلي — Python + FastAPI + SQLite (WAL) + واجهات HTML/CSS/JS.
- **بدون تثبيت Python** على الأجهزة الجديدة: كل الاعتماديات موجودة كـ wheels جاهزة للتثبيت أوفلاين.
- هوية الأجهزة افتراضية وقابلة للتخصيص عبر `PS_DEVICE_NAME` / `CS_DEVICE_NAME`.
- بيانات كل تطبيق منفصلة تمامًا — لا تداخل بين القاعدتين.

## التشغيل السريع

### على جهاز واحد (كلا البرنامجين)
```
START_ALL.bat
```
يفتح السيرفرين ويفتح تبويبين في المتصفح:
- http://127.0.0.1:8765 — محطة المشروعات
- http://127.0.0.1:8766 — شاشة القائد

### شاشة القائد على جهاز منفصل
```
START_COMMAND.bat
```
ثم من ⚙️ الإعدادات في الواجهة، غيّر عنوان المحطة إلى IP الجهاز الآخر مثل `http://192.168.1.10:8765`.

> ملاحظة: `START_*.bat` مفترضة Windows. على Linux/macOS شغّل `python3 run.py` من داخل فولدر كل برنامج.

## هيكل المشروع

```
├── START_ALL.bat               ← تشغيل البرنامجين معًا (ويندوز)
├── projects_station/           ← محطة المشروعات (المشغّل)
│   ├── run.py / run.sh
│   ├── START_PROGRAM.bat
│   ├── app/                    ← FastAPI + منطق العمل + قاعدة البيانات
│   ├── static/                 ← واجهة عربية RTL (HTML/CSS/JS + خرائط)
│   ├── tests/                  ← pytest
│   ├── tools/                  ← أدوات بناء بيانات أولية
│   ├── wheels/                 ← اعتماديات أوفلاين
│   └── data/                   ← (يُنشأ تلقائيًا: DB + الملفات المرفوعة)
├── command_screen/             ← شاشة القائد
│   ├── run.py
│   ├── START_COMMAND.bat
│   ├── app/                    ← sync.py (المزامنة) + main.py (API) + db.py
│   ├── static/                 ← واجهة القيادة
│   ├── tests/
│   └── wheels/
├── docs/                       ← سكربت الفيديو، العروض التقديمية، PDF
├── media/                      ← الفيديو الترويجي + لقطات الشاشة
└── tools/                      ← سكربتات توليد العروض والفيديو
```

## الإعدادات (متغيرات البيئة)

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `PS_DATA_DIR` | مجلد بيانات المحطة | `projects_station/data` |
| `PS_DB_PATH` | مسار قاعدة بيانات المحطة | داخل `PS_DATA_DIR` |
| `PS_DEVICE_NAME` | اسم جهاز المحطة في السجلات | `محطة قسم المشروعات` |
| `CS_DEVICE_NAME` | اسم جهاز القيادة في السجلات | `جهاز القيادة` |
| `CS_STATION_URL` | عنوان محطة المشروعات لشاشة القائد | `http://127.0.0.1:8765` |

## الاختبارات

```bash
cd projects_station && python -m pytest tests -v
cd command_screen && python -m pytest tests -v
```

تشمل الاختبارات: المزامنة، التنبيهات العاجلة، رحلة الأوامر كاملة (ذهابًا وإيابًا)، البيانات المرجعية، وسلوك انقطاع الاتصال.

## الوثائق

- `docs/` — سكربت الفيديو الترويجي (docx/txt)، عرض تقديمي (.pptx)، وملخص PDF.
- `media/` — الفيديو الترويجي + لقطات الشاشة الحقيقية للبرنامجين.
