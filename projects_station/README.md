# محطة قسم المشروعات — نموذج المحاكاة (الجزء الأول)

سلاح الإشارة — فوج إنشاءات خطية ثقيلة | نظام إدارة العمليات والمشروعات.
البرنامج كله بيشتغل محليًا ومن غير إنترنت: Python + FastAPI + SQLite + Leaflet.

## التشغيل على Windows
1. لازم يكون Python 3.10 أو أحدث متسطّب (https://www.python.org/downloads/)، وأثناء التسطيب علّم على «Add python.exe to PATH».
2. فك ضغط الملف ودوس دبل كليك على **START_PROGRAM.bat**.
   - أول مرة بس هيجهّز بيئة التشغيل من فولدر `wheels` (مش محتاج إنترنت).
   - المتصفح هيفتح لوحده على البرنامج: http://127.0.0.1:8765
3. عشان تقفل البرنامج، اقفل النافذة السودا.
4. **RESET_DEMO_DATA.bat** بيمسح كل البيانات ويرجّع البيانات التجريبية (وده موجود كمان في صفحة الإعدادات).

## سيناريو تجربة سريع
1. افتح «الفاكسات الواردة» وبعدين الفاكس **ف/2026/0412** (قطع كابل الأوتوستراد).
2. من خانة البحث اللي على الخريطة دوّر على المكان، وحدد نقطة العطل على مسار R-01 جنب النقط الرمادي (دي الأعطال القديمة)، واضغط «حفظ الموقع وفحص السجل».
   هيطلع تنبيه عاجل بالعطل المتكرر، ومعاه المفرزة القريبة وتأخر رد شركة المياه.
3. افتح «التقدير الفني» واضغط «حفظ وتوليد قائمة الاحتياجات»، وبعدين حدد حالة كل بند.
4. اضغط «حفظ وتمرير إلى القيادة». زرار «محاكاة ورود فاكس» بيضيف فاكس جديد عشوائي.

## البيانات
- قاعدة البيانات: `data/projects_station.db`، والفاكسات الأصلية في `data/uploads/`.
- كل البيانات التجريبية وهمية. الخريطة المحلية معمولة من بيانات OpenStreetMap لطرق القاهرة الكبرى وطرق مصر الرئيسية.
- اسم الجهاز الافتراضي «محطة قسم المشروعات» — يتغير بمتغير البيئة `PS_DEVICE_NAME`.
- إرفاق ملف الفاكس (PDF) بيتيح استخراج نصه تلقائيًا لنسخه في بطاقة الملخص — للملفات الممسوحة ضوئيًا استخدم الإدخال اليدوي.
- شاشة القائد (الجزء الثاني) هتستقبل العمليات اللي اتمررت من خلال `GET /api/command/feed`.

## للمطورين
- `pip install -r requirements.txt pytest httpx` وبعدها `python -m pytest tests`
- توثيق الـ API: http://127.0.0.1:8765/api/docs
